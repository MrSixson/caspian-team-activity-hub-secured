# Caspian Team Activity Hub

سامانه‌ی مدیریت کادر سرور Caspian: ثبت گزارش کار، تیکت، اخطار، وظایف و صورت‌جلسات.

> **قبل از دیپلوی، حتماً [`SECURITY.md`](./SECURITY.md) را بخوانید.**
> این فایل توضیح می‌دهد رمزها چگونه تنظیم می‌شوند و چه چیزی هنوز باید مهاجرت کند.

## اجرای محلی

**پیش‌نیاز:** Node.js 18 یا بالاتر

1. نصب وابستگی‌ها:
   ```bash
   npm install
   ```
2. ساخت فایل تنظیمات:
   ```bash
   cp .env.example .env
   ```
   سپس `GEMINI_API_KEY` و رمزهای اولیه (`SEED_*`) را پر کنید.
   اگر رمزها را خالی بگذارید، سرور در اولین اجرا رمزهای تصادفی می‌سازد و **یک بار** در کنسول چاپ می‌کند — همان‌جا یادداشتشان کنید.
3. اجرا:
   ```bash
   npm run dev
   ```

## دیپلوی

```bash
npm run build
NODE_ENV=production npm start
```

هنگام دیپلوی پشت پراکسی یا روی Cloud Run:

```bash
TRUST_PROXY=true
ALLOWED_ORIGINS=https://your-domain.example
```

`ALLOWED_ORIGINS` را خالی بگذارید تا فقط درخواست‌های هم‌مبدأ پذیرفته شوند. هرگز `*` قرار ندهید.

## ساختار

| مسیر | توضیح |
|---|---|
| `server.ts` | اپلیکیشن Express و تمام مسیرهای API به همراه نگهبان‌های دسترسی |
| `server/models.ts` | مدل‌های داده، سلسله‌مراتب رنک، ماتریس دسترسی، پاک‌سازی خروجی |
| `server/security.ts` | هش scrypt، مدیریت نشست، محدودیت نرخ |
| `server/db.ts` | ذخیره‌ساز JSON به همراه مهاجرت خودکار رمزهای قدیمی |
| `server/seed.ts` | حساب‌های اولیه (بدون رمز؛ رمز از متغیر محیطی) |
| `src/lib/api.ts` | کلاینت API با توکن نشست |
| `src/` | رابط کاربری React |

## نکات امنیتی کلیدی

- رمزها با scrypt هش می‌شوند و هرگز در پاسخ API، لاگ یا باندل فرانت‌اند ظاهر نمی‌شوند.
- هر مسیر API نیازمند نشست معتبر است؛ عملیات حساس نیازمند دسترسی متناظر.
- هیچ‌کس نمی‌تواند رنکی مساوی یا بالاتر از رنک خودش اعطا کند.
- `data_store.json` شامل هش رمزهاست، با مجوز `0600` نوشته می‌شود و در `.gitignore` قرار دارد. آن را کامیت نکنید.
